# UI 设计 Tokens

## 设计目标

界面用于持续扫描运行状态和执行高影响操作。视觉层级主要依靠排版、间距和边界，品牌色不承担所有信息强调。

## 颜色

Web 管理端使用 GitHub 风格的黑、白、冷灰结构色：`#0d1117` 导航、`#24292f` 主要动作、`#f6f8fa` 页面背景、`#ffffff` 内容表面和 `#d0d7de` 附近的边界层级。业务状态不做黑白化，继续使用 GitHub 风格的黄、绿、红、灰语义色，并结合边框、文字和圆点共同区分。

Admin App 与 Web 使用相同的黑、白、冷灰结构色和黄、绿、红、灰业务状态色。两端共享视觉 tokens 与状态含义，但保持各自的信息架构和布局方式：

Admin App 的移动组件沿用参考项目的圆角层级：控件 `14px`、列表和设置分组 `18px`、身份与摘要面层 `22px`、状态与轻标签使用 Pill。移动页面通过冷灰背景、白色分组表面、明显圆角和内部弱分隔建立层级，避免给每个列表行重复加外框。

| Token | 值 | 用途 |
| --- | --- | --- |
| `Ink` | `#17211f` | 主文本 |
| `Ink Soft` | `#53605d` | 次级文本 |
| `Paper` | `#f5f7f4` | 页面背景 |
| `Surface` | `#ffffff` | 控件与独立交互表面 |
| `Navigation` | `#192622` | Web 主导航 |
| `Action` | `#087f68` | 主要动作与焦点 |
| `Success` | `#237a4c` | 在线、正常、成功 |
| `Warning` | `#9b6306` | 排队、运行、检查中 |
| `Danger` | `#b53b35` | 离线、异常、失败 |
| `Offline` | `#68736f` | 停用、取消、归档 |

状态不能只通过颜色表达，必须同时显示稳定的状态名称和圆点或图标。

## 字体

- UI 字体：`Avenir Next`，按平台回退到 `Segoe UI`、`PingFang SC` 和 `Microsoft YaHei`。
- 日志、脚本、地址和 Revision：`SFMono-Regular`，按平台回退到 `Cascadia Code` 和 `Liberation Mono`。
- 页面标题：`22px / 700`；区块标题：`16px / 700`；正文：`14px / 400`；辅助信息：`11-12px`。
- 字间距统一为 `0`，不使用负字间距。

## 几何与间距

- 基础间距：`4 / 8 / 12 / 16 / 24 / 32 / 48px`。
- 常规圆角：`7px`；紧凑控件：`4px`；状态徽标使用胶囊形。
- Web 控件高度：`38-42px`；App 主要触控高度不低于 `44px`。
- 卡片仅用于确认面板、模态框和独立可选项。列表与页面区块采用连续表面。

## 断点

- `980px`：详情侧栏和表单摘要转为单列。
- `720px`：Web 侧栏收为 icon rail，表格隐藏低优先级列。
- `500px`：App 预览移除设备外壳，进入全屏运行态。

## 动效与焦点

- 模态与 Toast 使用 `160-200ms` 淡入和轻位移。
- 按钮按下只产生 `1px` 位移，不使用弹跳或装饰性缩放。
- `prefers-reduced-motion` 下关闭非必要动画。
- 所有键盘焦点使用半透明 `Action` 外轮廓，不依赖浏览器默认样式。
