# Web 与 Admin App 交互完善复核

## 结论

`docs/plans/2026-08-01-ui-interaction-refinement.md` 约定的 U1-U6 已在 `ui/` 设计源内形成可重复演示和自动化验证的交互基线，可以作为正式 Web 与 Flutter 客户端的交付参考。本轮未增加 SSH 密钥管理、应用授权页面或真实客户端工程，也未连接真实 API、SSH 或节点。

## 完成范围

- 建立统一命令任务状态、危险操作确认、Modal 焦点管理、就地失败反馈与防重复提交。
- 为现有表单补充字段校验、错误摘要、首错聚焦、SSH 端口、检查依赖失效和未保存导航保护。
- 用户停用、节点停用和应用归档均展示影响确认；失败场景保持原领域状态并允许重试。
- 部署覆盖排队、运行、成功、失败、取消中、已取消和执行中断；取消与重试保留独立状态和来源关系。
- 部署列表补充筛选摘要、清空和增量加载；日志补充上滚暂停、回到底部、复制、下载及工具失败反馈。
- App 二级页使用确定性父级返回，移动页面无 hover，触摸目标、大字体、键盘焦点和四类视口纳入回归。
- 增加锁定版本的 Playwright 配置与 `make ui-test`，测试自行管理 `8050` 预览进程。

## 验证证据

- `make ui-test`：27 项通过，覆盖 Web/App P0 路由、AE1-AE6、权限、生命周期、异常恢复和响应式约束。
- `make ui-check`：JavaScript、Python、尾随空格和 diff 检查通过。
- `make check`：Rust 格式、Clippy、全工作区测试、OpenAPI 一致性和 UI 静态检查通过。
- 视口：`1440x900`、`1024x768`、`390x844`、`360x800` 无页面级横向溢出；App 可见交互目标不小于 `44px`。
- 安全边界：密码未写入持久状态，私钥和 secret 内容未出现在页面、日志或 `localStorage`；仅展示稳定引用和脱敏摘要。

## 交付边界

- 设计源的异步延迟、领域数据和失败场景均为本地 mock，正式客户端必须以 API 返回和服务端权限为准。
- 浏览器文件下载只验证“已发起”反馈，不代表服务端日志文件已经生成或传输完成。
- 真实 SSE、SSH 执行、凭证管理和部署恢复继续由 API 契约及后续正式客户端实施覆盖。
