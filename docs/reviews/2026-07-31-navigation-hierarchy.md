# Web 设置导航与 App 我的页面收敛复核

## 结论

导航调整通过。App“我的”不再提供低价值的独立权限说明页；Web 设置工作区改用侧栏二级菜单，可在系统设置、用户管理和审计记录之间直接切换。

## 验证证据

- `#/app/mine` 的管理员视角只保留用户管理、个人资料、通知与偏好、关于四个入口。
- `#/app/mine/role` 进入“页面不存在”，不回退到个人资料或其他页面。
- `#/web/settings`、`#/web/settings/users`、`#/web/settings/audit` 均显示三个设置二级入口，且只有当前入口带 `aria-current="page"`。
- `#/web/settings/users/new` 与用户详情保持“用户管理”二级入口选中；用户详情保留“用户列表”三级返回。
- 设置根页不再显示用户管理和审计导航卡片；用户列表与审计页不再显示“返回设置”按钮。
- 普通用户访问设置深链时显示权限不足，主设置菜单和设置二级菜单均不渲染。
- `1440x900`、`1024x768` 和 `720x600` Web 无页面级横向溢出；窄屏二级菜单使用带 tooltip 的图标入口。
- `390x844` App“我的”无横向溢出，连续列表与退出按钮间距保持一致。
- 浏览器页面错误和控制台无异常，`make ui-check` 通过。

## 残留边界

- Web 二级菜单只在设置工作区展开，不设计折叠状态记忆。
- 用户详情属于用户管理下的三级页面，因此保留返回用户列表的上下文操作。
