# Web 设置导航与 App 我的页面收敛计划

## 目标

- App“我的”移除低价值的独立“权限说明”入口和页面。
- Web“设置”使用常驻二级菜单组织系统设置、用户管理和审计记录。
- 设置首页不再使用功能卡片承担子页面导航，详情页只保留必要的三级返回和页面操作。

## 范围

- `ui/assets/app.js`、`ui/assets/styles.css` 中的导航、路由和页面操作。
- `ui/docs/`、`ui/README.md` 与 `ui/tests/ui-preview.spec.js` 的同步调整。
- 桌面、窄屏 Web 和移动 App 的运行时回归。

## 非目标

- 不改变唯一管理员与普通用户的权限模型。
- 不移除用户详情中与当前账号相关的身份和权限摘要。
- 不增加新的系统管理功能或 App 设置页面。

## 执行单元

### U1：收敛 App 我的页面

- 移除“权限说明”设置行、`#/app/mine/role` 路由和独立页面内容。
- 保留身份区、用户管理、个人资料、通知偏好、关于和退出登录。
- 验证旧路由进入明确的未找到状态，普通用户视角不受影响。

### U2：增加 Web 设置二级菜单

- 在设置主导航激活时展示系统设置、用户管理、审计记录三个二级入口。
- 根据当前路由高亮对应二级入口，并提供 `aria-current`。
- 窄屏 Web 保留可识别的图标入口与 tooltip。
- 移除设置首页的用户 / 审计跳转卡片和子页面冗余“返回设置”按钮。

### U3：同步与验证

- 更新页面地图、Web / Flutter handoff、UI README 和回归规格。
- 执行 `make ui-check`。
- 在 `1440x900`、`1024x768` 和 `390x844` 检查导航层级、选中态、溢出和旧路由行为。

## 完成标准

- App“我的”不再显示或声明“权限说明”。
- Web 三个设置页面可从常驻二级菜单直接互相切换。
- 设置首页不再依赖内容区卡片进入用户和审计页面。
- 文档、路由、测试和运行时行为一致。

## 完成结果

- App“我的”已移除“权限说明”入口、页面内容和路由；旧地址进入明确的未找到页面。
- Web 设置主菜单已增加系统设置、用户管理、审计记录三个常驻二级入口。
- 设置根页已移除用户 / 审计导航卡片，用户列表和审计页已移除冗余“返回设置”。
- 新增用户与用户详情继续归属用户管理二级菜单，并保留必要的用户列表返回操作。
- 页面地图、组件清单、Web / Flutter handoff、UI README 和浏览器规格已同步。
- `make ui-check` 与 `1440x900`、`1024x768`、`720x600`、`390x844` 运行时回归通过。
- 复核记录见 `docs/reviews/2026-07-31-navigation-hierarchy.md`。
