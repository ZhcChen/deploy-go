# 非生产应用免密码查看 Env 明文

## 目标

管理员查看 `dev`、`test`、`staging` 应用的 Env 明文时，不再重复输入密码；`prod` 应用继续要求管理员密码重新认证。所有环境的写入和删除仍需现有限时授权。

## 实施单元

1. API：读取 Env 文件所属应用环境；非生产环境允许管理员会话直接读取，生产环境缺少授权时返回明确的重新认证错误。读取仍要求管理员身份、有效会话和 CSRF，并记录审计。
2. 管理端：进入 Env 页面先尝试无密码读取；生产环境收到重新认证错误后显示密码表单。非生产环境保存和删除仍要求密码授权。
3. 契约：OpenAPI 将 reveal 的 grant header 标为可选，并说明仅非生产环境可省略；重新生成 OpenAPI 和 TypeScript 客户端。
4. 验证：覆盖 prod 拒绝无授权、非生产允许无授权、普通用户仍拒绝、写入仍需授权，以及 OpenAPI 条件说明。

## 范围

仅修改 Deploy Go API、管理端、OpenAPI、测试和本计划。保留工作区已有 Env 软删除恢复改动及其他未提交内容。
