# 部署记录应用筛选

状态：就绪
来源：用户要求在部署记录页增加可搜索的应用下拉筛选。

## 目标与范围

帮助用户快速查找某应用的历史部署，与现有状态条件共同筛选全部记录。
覆盖管理端、列表接口、契约和分页；不修改业务应用或自动创建部署。

## 用户场景与验收

### US1：按应用查找部署

- 优先级：P1
- Given：用户可查看多个应用的部署。
- When：打开应用下拉、搜索并选择应用。
- Then：第一页及后续页仅显示该应用且符合状态条件的记录。
- 关键失败或边界场景：无匹配选项、无部署、应用加载失败、切换时旧请求尚未完成。

## 功能要求

- FR-001：提供可搜索的应用下拉，默认全部应用；可以恢复全部应用。
- FR-002：应用与状态条件在分页之前共同过滤；切换条件重置页码，缓存与游标不串用。
- FR-003：应用选项涵盖所有可访问应用，不受应用第一页限制；加载失败可重试。
- FR-004：保留管理员与普通用户权限边界、稳定排序和已有无筛选调用的行为。
- FR-005：下拉支持键盘选择、Escape 关闭、点击外部关闭和无匹配提示，保持页面样式。

## 成功标准

- SC-001：跨页过滤、切换/恢复、权限隔离和可搜索下拉通过本地回归及浏览器验证。

## 风险与验证要求

补 API 权限/分页回归和 UI 搜索/切换回归；执行生成客户端漂移检查、前端检查与隔离 Playwright 验证。
共享 Select 非搜索模式需保持现有行为，安排独立代码复核。
