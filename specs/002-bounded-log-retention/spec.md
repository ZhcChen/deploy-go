# 容量主导日志保留与集中诊断

状态：已验收；0.3.29正式控制面与正常节点已更新，证据见 docs/reviews/2026-10-08-bounded-log-retention.md。
来源：用户批准容量轮转建议；承接 docs/plans/2026-10-01-001-agent-storage-and-log-delivery-plan.md 已完成机制的容量与集中运行日志缺口。

## 目标与范围

让部署故障发生后可立即在控制面查询节点与平台诊断，并让本项目的日志磁盘/内存占用有明确容量边界。容量为主要保留依据，周期仅为辅助；保留部署历史和失败摘要，保护活动任务与未确认部署输出。只修改 deploy-go，不采集业务应用日志，不修改宿主机全局日志策略，不清理未知历史文件。

## 用户场景与验收

### US1：部署输出不会按部署量无限增长

- 优先级：P1
- Given：控制面已有大量已完成和活动部署输出。
- When：达到配置总预算。
- Then：先回收最旧已结束部署输出，保留部署状态/摘要；活动部署不被回收，无法安全回收则记录超预算诊断。
- 关键边界：旧配置缺新字段、并发写入、重启、失败部署、删除失败、受保护输出占满容量。

### US2：运行日志可轮转、重启后可查

- 优先级：P1
- Given：节点或控制面持续产生日志。
- When：到达分段或总容量限制、进程重启。
- Then：按容量回收最旧运行日志，重启后仍可查询保留记录；内存、单条和传输批次有界，丢失/回收可观察。

### US3：不用逐节点 SSH 即可关联诊断

- 优先级：P2
- Given：Agent、Broker、Executor 或 updater 出现异常。
- When：节点在线或连接恢复。
- Then：本项目脱敏结构化诊断集中到控制面，按节点、组件、任务/请求标识筛选；断线缓存达到上限时可观察缺口，日志采集不阻塞部署。

## 功能要求

- FR-001：部署输出全局默认预算 2 GiB，容量回收最旧已结束部署；现有单部署预算不变，周期配置继续兼容。
- FR-002：活动部署、未确认部署输出与恢复元数据不参与普通日志覆盖，预算不足必须明确诊断。
- FR-003：节点服务运行日志分段 16 MiB，本项目组件合计不超过 128 MiB；控制面集中运行日志分段 32 MiB，总计不超过 512 MiB。记录、缓冲和批次均有上限。
- FR-004：控制面运行日志持久化，重启不重置保留记录游标；旧游标过期需明确响应，不能静默冒充完整历史。
- FR-005：只采集本项目四个节点组件的白名单诊断，不读取业务日志、凭证、任意文件或宿主机全局 journal。上传身份绑定本节点，管理员查询授权保持不变。
- FR-006：节点日志上传同源序号可去重，断线恢复、响应丢失和本地覆盖产生的缺口须可识别；与可靠部署日志 ACK 合同独立。
- FR-007：补齐交接/恢复/缓存/清理关键诊断，成功流程只记录阶段摘要；不逐块打印，异常限频，不输出 Token、Env、原始错误正文或 URL。
- FR-008：旧 Agent 与既有日志协议继续工作；新功能只处理新日志命名空间，不盲删旧格式 retained 日志。无需业务应用改动。
- FR-009：可配置、可观测且可回滚；同步 OpenAPI、客户端与运行手册，真实发布按会话已有正式控制面自动发布授权执行，不自动重发业务部署。

## 成功标准

- SC-001：小预算 fixture 能验证最旧已结束部署回收，活动部署、状态、失败摘要不变；旧配置、并发写入和清理失败测试通过。
- SC-002：日志写入超过两个分段后总量不超预算，重启恢复、截断尾部、拒绝符号链接和有界读取测试通过；没有单条记录突破预算。
- SC-003：本地模拟节点上传、控制面重启、请求响应丢失、重复上传、鉴权拒绝、来源伪造和本地覆盖缺口可解释，部署功能不因运行日志采集异常退出。
- SC-004：管理员原日志查询继续可用，节点/组件筛选可用；敏感标记不出现在集中日志，内存和队列有字节预算，满额有可见统计。
- SC-005：独立复核、聚焦回归、规格收敛及正式发布检查完成；授权发布后记录控制面健康及正常节点自动升级结果，不把配置声明当真实峰值测量。

## 风险与验证要求

高风险点是回收范围、磁盘故障、跨身份日志读取、落盘/上传去重及内存边界。须实际小预算轮转、恢复、权限和 HTTP fixture 验证，复用现有 API/Agent 测试与本机隔离 Docker；不操作业务应用。周期非主限制，不因缩短周期清理恢复元数据。容量定义为日志有效载荷/受管分段文件，不等同于整个 SQLite 文件、宿主机 journald 或业务目录大小。

## 未决事项

无。分段和容量是批准的默认初值，可配置；服务运行日志允许容量覆盖但必须标明缺口，部署输出仍采用已有落库 ACK 保护。
